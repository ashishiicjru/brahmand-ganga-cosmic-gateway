# Cosmos Tour Pro v4.0

Real 3D asset pipeline, visible launch control, engineering telemetry and model fetcher.

## Model sources
NASA 3D Resources for rocket/satellite assets; Open Water marine assets with their stated Creative Commons licenses.

## Launch
The launch sequence is an educational Three.js simulation. It models countdown, ascent, stage separation, engine cutoff, orbital insertion and payload separation. It is not a command/control interface for a physical vehicle.
